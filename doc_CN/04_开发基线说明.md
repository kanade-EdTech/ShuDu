# 虚拟歌手数独——M0 开发基线说明

> 基线版本：0.1.0-m0  
> 完成日期：2026-10-03  
> 状态：M0 已完成，Chrome 61 与真机兼容性尚未实测

## 1. 基线结论

项目采用零第三方运行时依赖的离线 H5 基线。根目录的 `index.html` 是开发预览入口，也是构建后两个平台产物的根入口。页面样式和脚本已外置，生产包只包含明确白名单中的页面、样式、经典脚本和本地图片。

M0 只建立工程、构建、校验和视觉回归基线，不实现数独业务交互。`app.js` 目前只登记应用版本与 M0 就绪状态。

## 2. 目录职责

```text
index.html                 # 单页入口
style.css                  # Chrome 61 基线样式
app.js                     # ES2017 经典脚本入口
assets/                    # SVG 等本地视觉资源
公式服头像/                # 1–9 默认角色素材
scripts/build.mjs          # 生成 Toy / 小红书产物
scripts/verify-build.mjs   # 结构、能力、路径与体积门禁
tests/                     # Node 内置测试运行器的冒烟测试
dist/toy/                  # B站 Toy 构建产物，不纳入版本库
dist/xhs/                  # 小红书小工具构建产物，不纳入版本库
doc_CN/                    # 中文设计与开发文档
```

数独领域模块、题库脚本和存储服务在 M1–M3 按职责加入，不在 M0 创建无内容的占位文件。

## 3. 本地命令

项目要求 Node.js 18 或更高版本，不需要安装 npm 依赖。

```text
npm test        运行开发基线冒烟测试
npm run build   生成 dist/toy 与 dist/xhs
npm run verify  校验两个平台的已构建产物
npm run check   依次执行测试、构建与产物校验
```

## 4. 构建白名单

构建脚本只复制以下内容：

- `index.html`
- `style.css`
- `app.js`
- `assets/`
- `公式服头像/`

设计文档、测试、构建脚本、原始题库、截图、Git 元数据、依赖目录和 source map 不会进入发布产物。

## 5. 自动门禁

`verify-build.mjs` 当前检查：

- 构建根目录存在且仅存在一个 HTML 入口。
- 发布文件扩展名符合小工具静态包范围。
- 没有外部 URL、内联脚本、行内事件、module、iframe、object 或 base。
- 没有网络请求、Worker、WASM、动态执行、剪贴板和定位等禁用能力。
- HTML/CSS 中的相对资源全部存在且没有越出构建根目录。
- 解压后文件总量不超过 10 MiB；超过 2 MiB 时发出体验预算警告。

本门禁是静态检查，不能替代 Chrome 61、平台模拟器和真机测试。

## 6. 视觉基线

- 设计：66CCFF 音符版 V2。
- 默认视口：500×900 手机竖屏。
- 拆分前参考截图：`output/playwright/ui-prototype/simple-note-v2.png`。
- M0 构建产物截图：`output/playwright/m0-baseline-500x900.png`。
- 简易模式默认角色：1 洛天依、2 乐正绫、3 星尘、4 言和。
- M0 拆分前后应保持相同布局和主要视觉层级。

## 7. M1 入口条件

满足以下条件后进入 M1：

1. `npm run check` 全部通过。
2. Toy 与小红书两个产物均可从本地 `index.html` 离线打开。
3. 4×4、9×9 静态模式切换与原界面一致。
4. 拆分后的手机截图无明显视觉回归。
5. 已知未验证项明确记录为 Chrome 61、平台模拟器和真机实测。
