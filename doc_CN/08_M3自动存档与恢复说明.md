# M3 自动存档与恢复说明

> 版本：v0.7.0-m3  
> 完成日期：2026-10-04  
> 状态：已完成

## 1. 本阶段结果

简易 4×4 与高难 9×9 现在各自保留一份最近的未完成棋局。刷新或重新打开页面后，可恢复对应题目、9×9 难度、盘面、当前选格、步数、用时和撤销历史；切换模式不会覆盖另一模式的进度。

已完成棋局不作为“未完成进度”继续恢复，下次启动会为该模式保留新局逻辑。

## 2. 模块与存档契约

- `storage.js`：封装 localStorage 读、写、清除和异常降级。
- `domain.js` 的 `restoreGameState`：恢复前验证题目 ID、模式、数组长度、数值范围、预置格、选格、步数和历史上限，并重新计算完成状态。
- `app.js`：按稳定题目 ID 从 4×4 或四档 9×9 运行时题库重建 Puzzle，再交给领域层恢复 GameState。
- 存储键：`vocal-sudoku-progress-v1`。
- `schemaVersion`：当前为 `1`。未知版本按损坏或不支持存档处理，删除本应用自己的旧值并安全进入新局；后续版本可在存储模块中加入逐版迁移。

存档顶层包含 `currentMode`、`currentHardDifficulty`、`updatedAt` 和 `games.simple` / `games.hard`。两个游戏槽仅保存可序列化领域数据，不保存 DOM、图片对象或题目完整解答。

## 3. 保存与恢复时机

以下操作后立即保存：

- 选格、填入、清除和撤销；
- 新开一局；
- 简易 / 高难模式切换；
- 9×9 难度切换；
- 页面进入隐藏状态或触发 `pagehide`。

当前数据量很小，因此使用立即写入，不引入定时器或后台任务，符合离线小工具容器约束。

## 4. 异常降级

- localStorage 被禁用、访问被拒绝或容量写满时，当前会话的内存棋局仍可继续操作。
- 保存失败后，顶部状态条追加“当前进度未保存”，不会阻塞落子或导致白屏。
- JSON 损坏、结构版本不支持、题目已从题库移除、预置格被篡改或历史非法时，只放弃对应存档并进入新局。
- 恢复后的 `status` 不信任存档原值，而是根据盘面和当前题目重新计算。

## 5. 验证证据

- 自动化测试：24 项全部通过，其中包含正常存取、损坏 JSON、存储拒绝/写满、合法状态恢复、预置格篡改和非法历史拒绝。
- 双平台构建：`dist/toy` 与 `dist/xhs` 均为 17 个文件、约 1.84 MiB。
- 小工具官方静态审计：Toy 与小红书产物均为 `PASS`，0 warning。
- Chrome 500×900 浏览器回归：在 9×9 魔鬼难度落子后刷新，题目 ID、难度、落子、撤销历史、模式选中与恢复提示全部一致。
- 截图：`../output/playwright/m3-save-restore-500x900.png`。

## 6. 已知边界

IndexedDB 仍留给 M4 的用户头像与音频二进制资源，棋局、用时等小数据继续使用 localStorage。当前计时按整秒累计；页面隐藏时先落盘，重新可见后再继续计时。
