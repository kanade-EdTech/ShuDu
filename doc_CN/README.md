当前静态界面入口为 [`../index.html`](../index.html)，背景图案素材为 [`../assets/music-note-background.svg`](../assets/music-note-background.svg)。

当前设计的核心约定：

- 简易模式 = 4×4 数独 + 4 人图标集。
- 高难模式 = 9×9 数独 + 9 人图标集，并按源文件选择简单、中等、困难、魔鬼四档题目。
- 两种模式各自保留最近未完成进度。
- 小红书小工具保留内置 BGM，但不提供本地音频导入；B站 Toy 在能力检测通过后提供导入。
- `公式服头像` 已包含 9 张默认角色头像，发布前仍需确认素材授权与小尺寸辨识度。
