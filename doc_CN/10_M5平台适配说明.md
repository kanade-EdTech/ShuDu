# M5 平台适配说明

> 版本：v0.9.0-m5  
> 日期：2026-10-11  
> 状态：本地实现与验证已完成；平台容器、Chrome 61 和真机待验收

## 1. 平台行为

新增 `platform.js`，从构建标记 `data-platform` 或实际 `window.xhs.miniTool` 对象识别平台，不使用 UA 猜测。能力接口提供图片选择、音频选择、IndexedDB 和内置音频支持检查。Toy/浏览器保留用户音频导入，小红书构建移除 `audio-library.js`、音频文件选择器和导入入口。

视觉窗口高度通过 `visualViewport` 检测后增强，无该对象时使用 `innerHeight`。窄屏与短屏取消固定最小高度，顶部与底部不被 Flex 压缩，中间内容保持独立滚动；弹层限制在可见窗口内。顶部、底部兼容模拟器注入的安全区变量和设备 `env()` 安全区。

内置音乐沿用 M4 程序合成曲，失败时静音降级；头像、题库和脚本都使用随包相对路径。

## 2. 构建与包结构

运行 `npm run check` 完成测试、双平台构建和静态资源门禁。Windows 下运行 `npm run package` 重建并生成：

| 产物 | 文件数 | ZIP 字节数 | 解压后体积 |
| --- | ---: | ---: | ---: |
| `dist/vocal-sudoku-toy.zip` | 20 | 1,431,073 | 约 1.87 MiB |
| `dist/vocal-sudoku-xhs.zip` | 19 | 1,428,850 | 约 1.87 MiB |

ZIP 根目录直接包含 `index.html`。打包器使用 Windows 自带 .NET ZIP 库；打包完成后逐项打开条目，对比源文件 SHA-256，确保中文资源文件名与内容完整。两份包均未包含原始题库、构建脚本、文档、临时浏览器配置或 source map。

`npm run preview:platform` 启动本地预览：

- Toy 子路径：`http://127.0.0.1:4173/toy/demo/`。
- 小红书：`http://127.0.0.1:4173/xhs/`。

本地预览服务器通过响应头限制脚本为同源外置脚本，图片支持本地/Blob，Toy 音频允许 Blob，小红书媒体源仅允许同源。CSP 仅用于本地测试，不在产物 HTML 中设置自建 CSP。
